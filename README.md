# Odin Recipes

## About this project
This is my solution to The Odin Project's Foundations course "Project: Recipes."
The goal was to practice core HTML by building a basic multi-page recipe website:
a home page that links out to a handful of individual recipe pages, each following
the same consistent structure (image, description, ingredients, steps).

Through this project I practiced:
-Writing standard HTML consistently across multiple files
-Structuring content with headings (`h1`, `h2`), paragraphs, and both ordered and
  unordered lists
-Linking between pages with relative paths (`recipes/file.html` and `../index.html`)
-Organizing a small multi-page site into a sensible folder structure (`recipes/`
  subdirectory)
-Using Git to track progress with small, meaningful commits, and publishing the
  finished site with GitHub Pages

No CSS was used, per the assignment. Styling is a project I'll revisit later in
the curriculum.

The recipes included are:
-Filipino Fried Chicken
-Sinigang na Baboy
-Chicken Adobo

## How to view
Open `index.html` in a browser, or visit the published GitHub Pages site:
`https://cgoliveros10-sample.github.io/odin-recipe`
